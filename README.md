# Lorym — отдельный прототип

Интерактивный прототип Lorym на React, Vite, Tailwind CSS 4 и shadcn/ui. Это локальная демонстрация интерфейса; рабочий сервис и ИИ к ней не подключены.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте адрес Vite, обычно `http://localhost:5173/`.

## Логика продукта

- **Пространство** — предметная область. В нём хранятся встречи, их источники, резюме и документы.
- **Встреча** может содержать несколько записей и вложений. У каждой записи свой транскрипт; части одного разговора можно показать общим транскриптом.
- **Резюме встречи** связано ровно с одной встречей. Оно доступно внутри встречи, в карточке записи и в общей «Базе знаний». Резюме можно перегенерировать по другому шаблону аккаунта.
- **Конспект** может опираться на несколько встреч одного пространства. В «Базе знаний» можно выбрать источники, создать документ и вернуться из него к каждой встрече.
- **Записи**, **База знаний**, **Шаблоны** и **Задачи** — общие разделы с фильтром по пространствам. Поиск в базе знаний охватывает содержимое документов и названия связанных встреч.

Данные прототипа сохраняются в браузере. Загруженные файлы доступны для локального воспроизведения только до перезагрузки страницы. Автоматическая расшифровка, генерация резюме и сводного конспекта по нескольким встречам пока не запускаются: создание конспекта открывает связанный с источниками черновик для редактирования.
